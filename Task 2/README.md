# Creative Academy

A clean and modern landing page for an online learning platform, built with HTML and CSS. The design includes a navigation bar, hero section, course cards, and a polished footer.

## Project Overview

This page is designed to promote a creative academy and encourage visitors to explore top courses and start their learning journey. The layout features:

- A branded navigation bar
- A full-width hero banner with a background image
- Clear call-to-action buttons
- Course cards for different learning tracks
- A simple and elegant footer

## Files Included

- `index.html` — page structure and content
- `style.css` — visual styling and layout
- `Images/` — project image assets

## Technologies Used

- HTML5
- CSS3
