# NextGen Internship

This repository contains front-end web design tasks completed as part of the NextGen internship program. Each task focuses on building responsive and visually clean webpages using HTML and CSS.

## Repository Structure

- `Task 1/` — Personal portfolio website
- `Task 2/` — Creative Academy landing page

## Task 1

A simple personal portfolio website designed to showcase a front-end developer profile, skills, work experience, and contact details.

See the project in:
- `Task 1/index.html`
- `Task 1/README.md`

## Task 2

A modern educational landing page for a creative academy, featuring a hero banner, course highlights, and a clean, modern design.

See the project in:
- `Task 2/index.html`
- `Task 2/README.md`

## Technologies Used

- HTML5
- CSS3

## How to View

Visit the [NextGen Internship website](https://badryounis.github.io/NextGen/) to view the projects online.

Open any task folder and launch the `index.html` file in a browser.
