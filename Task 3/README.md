# Explore The World

A responsive travel website for exploring popular destinations around the world. It features destination cards, navigation controls, and JavaScript-powered interactions.

## Project Overview

The website includes:

- A responsive navigation bar
- A travel-focused hero section
- Destination details for Paris, Tokyo, Rome, and Cairo
- Previous and next destination controls
- Clickable destination dots
- An interactive "Explore More" button

## Files Included

- `index.html` — page structure and content
- `style.css` — visual styling and responsive layout
- `script.js` — destination slider and interactive behavior

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to View

Open `index.html` in your browser to view the website locally.
