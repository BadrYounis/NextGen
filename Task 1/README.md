# My Portfolio

A simple personal portfolio website built with HTML to showcase a front-end developer profile, skills, work experience, and contact information.

## Live Demo

[My Portfolio](https://badryounis.github.io/NextGen/)

## Project Overview

This portfolio includes:

- A professional introduction and personal profile
- Skill highlights for front-end development
- Experience timeline with company details and logos
- A contact form for reaching out

## Files Included

- `index.html` — main portfolio page
- `techcorp.png` — company logo asset
- `digital-agency-pro.png` — company logo asset
- `web-design-studio.png` — company logo asset

## How to View

Open `index.html` in your browser to view the portfolio locally.
